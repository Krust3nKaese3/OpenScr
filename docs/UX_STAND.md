# UX-Stand der Mutter-App

Stand: 24. November 2026

Die Oberfläche von OpenScr selbst, also der Container und nicht die einzelnen OpenScrapps, ist an diesem Punkt ein brauchbarer Stand. Weitere UX-Arbeit baut darauf auf. Die OpenScrapps haben einen eigenen Stand und sind hier nicht mitgemeint.

Dazu gehört:

- Start mit dem Schriftzug OpenScrapps, App-Karten und der Leiste unten (Start, QR, Einstellungen) aus denselben Outline-Icons.
- Jede Karte hat oben rechts ein Zahnrad. Das öffnet dasselbe Menü wie ein langes Drücken.
- Installieren aus dem Katalog zeigt am Knopf einen Ladekreis. Danach liegt die neue Karte in der Übersicht, wird bei Bedarf hingesrollt und wippt einmal. Eine Erfolgsmeldung gibt es dafür nicht.
- Auf „Scrapp hinzufügen“ bleibt nur das Logo. Zurück geht über die Leiste, Datenschutz über die Einstellungen.
- Im Browser kann eine installierte App ihre Dateien aus einem Ordner auf dem PC lesen. Ohne Pfad gilt der GitHub-Stand.
